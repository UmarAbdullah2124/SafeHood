# SafeHood

A real-time community safety app built with Flutter and Firebase, featuring SOS alerts, live location tracking, geofencing, community forums, verified responders, and push notifications.

## Technologies

* Flutter
* Dart
* Firebase
* Firebase Realtime Database
* Firebase Cloud Messaging (FCM)
* Google Maps API

## Features

* SOS emergency alerts
* Real-time location tracking
* Geofencing
* Community forums
* Verified responders
* Push notifications

## Setup

1. Clone the repository.
2. Install Flutter dependencies:

```bash
flutter pub get
```

3. Configure the required Firebase and Google Maps credentials.
4. Run the application:

```bash
flutter run
```
